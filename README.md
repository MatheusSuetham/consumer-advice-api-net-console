# Consumer Advice API - .NET Console

Aplicação console desenvolvida em C#/.NET para consumir a API de conselhos aleatórios:

https://api.adviceslip.com/advice

## Funcionamento

A aplicação realiza uma requisição HTTP para a API, interpreta o JSON retornado e exibe o conselho no console.

Exemplo de saída:

```text
Conselho de Hoje:
Things are just things. Don't get too attached to them.
```

## Tecnologias

- C#
- .NET 8
- HttpClient
- System.Text.Json

## Como executar

1. Tenha o .NET 8 SDK instalado.
2. Clone este repositório.
3. Entre na pasta do projeto:

```bash
cd ConsumerAdviceApi
```

4. Execute:

```bash
dotnet run
```
